# understand-mode（/understand）

Claude Code の出力を、付箋のホワイトボードで寄り道しながら理解するためのスキルです。

- 本筋（Claudeの出力・コード・未コミットの差分）の文や行を選ぶと、質問・詳しく・用語・図・データ・レビューの付箋が生えます
- コードと差分は行番号付きで表示し、選んだ行番号をClaudeに伝えます
- 説明に載るコードの抜粋には、ファイル名と実際の行番号が付きます
- 付箋の中でも会話でき、回答の文を選べば子付箋になります
- 図は Mermaid、グラフは Vega-Lite で描きます
- データの付箋では、SQLを「承認して実行」したときだけ実行し、結果の表・グラフ・SQLを並べて見られます。どうやってデータを取るかは、あなたの Claude がいつものやり方でやります
- Claude Code を確認なしのモード（`bypassPermissions`）で使っているときは、アプリも聞き返しません。提案されたSQLはそのまま実行されます
- 「理解を終える」で、本筋に影響ありの付箋からメインに返す文を下書きし、送ったら寄り道の記録は破棄します

## 必要なもの

- Claude Code（`claude` コマンド）
- PRを対象にする場合：`gh` コマンド（なければブランチの差分で代わりにします）
- Node.js 18 以上
- データの付箋でSQLを実行する場合：あなたの Claude が普段データを取れていること（psql でも Redash の MCP でも、いつものやり方のままで構いません）
- PRモードは `gh` があれば使いますが、作者の環境では GitHub につなげなかったため、ブランチ差分での代替手順でしか試していません

追加の npm パッケージは不要です。図とグラフのライブラリは同梱しています（ネット接続がなくても描画できます）。

動作を確認しているのは macOS と Linux です。Windows では試していません。

## インストール

```bash
git clone <このリポジトリのURL>
cd understand-mode
bash install.sh
```

`~/.claude/skills/understand/` にコピーされます。Claude Code を開き直すと `/understand` が使えます。

## 使い方

1. Claude Code で調査や実装をしてもらう
2. わからないと思ったら `/understand`
   - やりたいことを書く：`/understand このPRを理解したい`、`/understand #128のPR`、`/understand 認証の流れを理解したい`
     → メインのClaudeが調べて、概要→変更のまとまり→必要な分だけのコード抜粋→読むときのポイント の順に説明文書を作ってから開きます
   - 直前の回答：`/understand`
   - ファイル：`/understand src/report.py`
   - 未コミットの変更をレビュー：`/understand diff`（ブランチとの差分は `/understand diff main`）
3. ブラウザでホワイトボードが開くので、わからない箇所を選択して付箋を作る
4. 理解できたら「理解を終える」→ 返す付箋を選ぶ →「メインに送って閉じる」
5. Claude Code に戻って「終わった」と伝える。メインのClaudeが内容を受けて本筋を直します（指摘が違う場合は理由を示して押し返します）

### 操作

| 操作 | やり方 |
| --- | --- |
| 付箋を作る | 本筋や付箋の回答の文を選択 → メニュー |
| 続けて質問 | 付箋の入力欄で ⌘/Ctrl + Enter |
| 付箋を動かす | 付箋の見出しをドラッグ |
| たたむ・開く | 「たたむ」ボタン／たたんだタブをクリック。まとめて片付けたいときは上の「すべてたたむ」 |
| 付箋の大きさを変える | 右下のつまみをドラッグ（ダブルクリックで元の大きさに戻ります） |
| ボードを動かす | 背景をドラッグ、またはスクロール |
| 拡大・縮小 | ⌘/Ctrl + スクロール、または下のツールバー |
| グラフの値を質問 | グラフの点や棒をクリック |

設定ファイルはありません。モデルも道具もSQLの書き方も、分身がメインのセッションから引き継ぎます。

変えられるのは待ち時間だけです。重い調べものに時間がかかるようなら、`UNDERSTAND_TIMEOUT_SEC=600` のように環境変数で伸ばせます（既定は300秒）。

## しくみ

- 質問のたびに `claude -p --resume <メインのセッション> --fork-session` を実行します。メインの文脈を引き継いだ分身が答えるので、メインの会話は汚れません
- 付箋の続きの質問はその付箋のセッションに、子付箋は親の付箋のセッションから分岐します
- 閉じると、このアプリが作った分岐セッションの記録（`~/.claude/projects/` の該当ファイル）だけを削除します。メインのセッションには触れません

## 注意

- 質問1回ごとに、メインの会話全体を読み込みます。会話が長いと費用がかかります（2回目以降はキャッシュが効きます）
- グラフの値は、Claudeが取得して返した結果の表から描いています。アプリがデータベースに直接つないでいるわけではありません
- このアプリは接続先も道具も持ちません。承認のときに「いつものやり方で実行して」と頼むだけです。トンネルや認証の用意は、普段どおり先に済ませておいてください
- 実行できるのは `select`（または `with`）で始まる1文だけです。書き込みや複数文はアプリ側で弾きます
- 実行できる範囲は、あなたが普段 Claude Code に与えている許可のままです。アプリが許可を足すことはありません
- 承認を挟むかどうかも、メインのセッションの権限モードに合わせます。アプリが独自に厳しくすることはありません
- 承認前の実行を止めているのは `Bash` とファイル編集の禁止です。psql や bq のようなコマンド系は止まりますが、**MCPの道具は名前が分からないので止めきれません**。MCP経由でデータを取っている方はご注意ください
- アプリのURLには合言葉が入っています。この合言葉がないと操作できないので、**URLを人に見せないでください**。同じマシンの別のページやプロセスからの操作を、これで防いでいます
- 付箋の内容は、ブラウザのタブを閉じるまでそのタブの中だけに保存されます

## アンインストール

```bash
rm -rf ~/.claude/skills/understand
```

## 開発する人へ

続きの開発は `CLAUDE.md` と `docs/architecture.md` から読んでください。`npm run mock` で、費用をかけずに画面を動かせます。

```bash
npm run mock       # 偽の claude で起動（費用ゼロ）
npm run test:sql   # SQL実行まわりの確認（ClaudeもDBも使わない）
npm i && npm run test:e2e   # mock を動かしたまま、画面を一通り自動操作
```
